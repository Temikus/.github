# Security Policy

This is the default policy for Temikus repositories that don't have their own `SECURITY.md`.

## Supported versions

Only the latest release receives security fixes. Please upgrade before reporting an issue against an older one.

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue: open the repository's **Security** tab and choose **Report a vulnerability**.

Include, where you can:

1. A description of the issue and its impact.
2. Steps to reproduce, or a proof of concept.
3. The affected version.
4. Any suggested fix or mitigation.

These are hobby projects maintained in spare time, so expect an acknowledgement within a week and a fix timeline agreed with you once the report is triaged. Please give a reasonable window for a fix before disclosing publicly.
